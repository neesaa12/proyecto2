# ADR-0001 · Guardar las acciones en un fichero JSON

## Contexto

Quiero usar la herramienta para reunir los PDF y las capturas de una entrega de clase y generar un índice. Los tipos de archivo y las carpetas de destino pueden cambiar de una entrega a otra.

## Decisión

Guardo las acciones en `acciones.json`. Cada acción tiene un identificador, una operación, un patrón y un destino. La acción que genera el índice también indica en qué carpeta empieza a buscar.

## Motivo

Reunir los PDF y reunir las capturas son dos usos de la misma operación de copia. Lo que cambia es el patrón de búsqueda y la carpeta de destino. Guardar esos datos en JSON me permite definir otra acción de copia sin modificar el código Python.

## Consecuencias

El programa tendrá que validar el fichero antes de ejecutar las acciones. Si falta un campo o se repite un identificador, deberá indicar qué acción hay que corregir. Para incorporar una operación completamente nueva, sí habrá que programarla en Python.
